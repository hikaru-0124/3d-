# PROP SHIFT — 変身かくれんぼ

ブラウザで遊べる3Dオンライン変身かくれんぼです。箱・ドラム缶・コーンに変身して隠れる側と、探して撃つハンターに分かれて対戦します。Three.jsとWebSocketを使い、役割・移動・変身・射撃・勝敗はサーバーで判定します。従来のNEON CROSSFIREシューティングもゲーム選択から遊べます。

## 起動

```bash
npm ci
npm start
```

http://localhost:3000 を開きます。`PORT` で変更できます。

## 変身かくれんぼ

1. ゲーム種類を「変身かくれんぼ」にします。
2. 「ボットで練習」なら自分と3体のボットで遊べます。「オンライン対戦」は同じROOM IDに2〜12人で参加します。
3. 最初の20秒は隠れる時間。ハンターは目隠しされ、移動・射撃ができません。
4. 続く90秒でハンターが隠れている全員を見つけると勝ち。時間まで1人でも生き残れば隠れる側の勝ちです。
5. 結果表示の8秒後にハンターを交代して再開します。倒された人や途中参加者は次のラウンドで参加します。同じラウンド中のリスポーンはありません。

- **WASD / 矢印**：移動、**マウス**：視点、**Shift**：ダッシュ。
- 隠れる側：**E**で木箱 → ドラム缶 → コーンへ変身。三人称視点で自分の姿を見られます。視点を回しても小道具自体は回転しません。
- ハンター：**左クリック**で射撃、**R**でリロード。24発マガジン、予備弾は無制限。誤射1発につきHPが5減り、HPが0になると脱落します。命中1発は25ダメージです。
- ハント中は20秒ごとに隠れる側の位置に青い輪と物音のヒントが2.5秒間出ます。
- マップにある32個の小道具と、変身したプレイヤーは同じ見た目です。小道具は弾と移動を遮ります。
- **Esc**でメニュー。感度と効果音を設定できます。練習はメニュー中に一時停止しますが、結果表示の8秒カウントは進みます。オンライン対戦はメニュー中も進行します。
- 練習のボットは隠れる・巡回する・近くの動きや物音を探す簡易AIです。

## Codespacesでオンライン対戦

1. `npm start` を実行します。
2. 「ポート」タブで3000番の可視性を **Public / 公開** にします。
3. ブラウザで開き、「オンライン対戦」でルームに参加します。
4. 「招待リンクをコピー」で共有します。ゲーム種類とROOM IDがURLに含まれます。

ルームIDはパスワードではありません。公開URLを知る人が参加できます。Codespaceの停止中は遊べません。PCのWebGL対応ブラウザ推奨。スマートフォンのタッチ操作には対応していません。

## シューティングアリーナ

ゲーム種類で「シューティングアリーナ」を選ぶと従来の最大12人PvP・ボット練習で遊べます。同じROOM IDでも変身かくれんぼとは別の対戦になります。

- 100HP、1発25ダメージ。倒されたら3秒後に復帰します。
- 復帰後5秒間は射撃しても無敵が続きます。敵との距離と遮蔽物を考慮して出現位置を選びます。
- Shift中は射撃できません。Rで1.6秒のリロード、弾切れ時は自動リロードです。

## 検証

```bash
npm test
```

衝突・レイ判定・安全な出現位置・リロード・無敵時間と、実WebSocketによる参加・ルーム分離・射撃・復帰を検証します。かくれんぼでは役割交代、準備中の行動制限、変身の制限、ヒント、勝敗、途中参加、練習の一時停止を確認します。
