# NEON CROSSFIRE

Codespacesで動くブラウザ3D・オンラインPvP FPSです。最大12人のフリーフォーオール。Three.jsとWebSocketを使い、移動・遮蔽物の判定・射撃・HP・キル数はサーバー側で処理します。

## 起動

```bash
npm ci
npm start
```

サーバーは `0.0.0.0:3000` で待ち受けます。ローカルでは http://localhost:3000 を開きます。`PORT` 環境変数でポートを変更できます。

## Codespacesでオンライン対戦

1. ターミナルで `npm start` を実行します。
2. Codespacesの「ポート」タブで **3000** を追加します（devcontainerの再構築後は自動転送）。
3. 3000番の「ポートの可視性」を **Public / 公開** にします。
4. 「ブラウザーで開く」でゲームを開き、名前とROOM IDを入力します。
5. 「招待リンクをコピー」で友達にURLを共有します。同じROOM IDで参加してください。

公開ポートはURLを知る人がアクセスできます。プライベートルームIDはマッチ分割用であり、認証やパスワードではありません。Codespaceが停止するとゲームも停止します。常時稼働サービスではありません。

## 遊び方

- PCのWebGL対応ブラウザ推奨。WASD / 矢印キーで移動、マウスで視点、左クリック長押しで射撃。
- 参加後「戦闘を開始」をクリックするとマウスを捕捉。Escで解除します。
- HP100、1発25ダメージ、倒されたら3秒後に自動リスポーン。
- リスポーン直後は1.5秒の保護。射撃すると解除されます。
- スコアは接続中のみ保持。退出するとリセットされます。
- スマートフォン向けタッチ操作、ボット、アカウント、永続ランキングはありません。

## 検証

```bash
npm test
```

衝突とレイ判定、実際のWebSocketによる複数参加・ルーム分離・射撃・キル・リスポーン・退出を確認します。
